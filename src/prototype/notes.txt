- Primitives that follow the scheme <dialect.op [vars] : [types]> should be modeled as expressions.
Maybe in the actual implementation each of these should be modeled as a inherited subtype of Expression.
Examples:
scf.yield %x : i32
arith.addi %x, %y : i32
An expection is memref.dealloc %0 : memref<8x64xf32> because it uses a special type


- Attributes not implemented

- Bool-like types are to be declared as type 'i1'

- If an operation can take any type (i.e. float and int), the operation must be declared twice
once with int and once with float
